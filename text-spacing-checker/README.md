# text-spacing-checker

WCAG 2.2達成基準1.4.12で示される文字間隔をページへ一時的に適用し、文字の欠落や重なりを目視確認しやすくします。`overflow:hidden`／`clip` により内容が切れている可能性がある要素は枠で表示します。

適用する値は、行の高さ `1.5`、字間 `0.12em`、単語間 `0.16em`、段落後の間隔 `2em` です。

## 使用方法

次のコードをブラウザのブックマークURLとして登録し、検査対象ページで実行します。ページ全体を確認し、文字の欠落、重なり、コントロールからのはみ出しがないか確認してください。もう一度実行するか、右上の「終了」を押すと適用したスタイルと表示を削除します。

## 確認時の注意

`文字切れ?` はスクロール寸法と `overflow` から求めた候補であり、合否判定ではありません。枠がなくても、固定高、絶対配置、重なり、横スクロール、操作不能などをページ全体で確認してください。サイトのContent Security Policyによってインラインスタイルが禁止されている場合は適用できないことがあります。

参考：[Understanding Success Criterion 1.4.12: Text Spacing](https://www.w3.org/WAI/WCAG22/Understanding/text-spacing)

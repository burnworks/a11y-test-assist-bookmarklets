# force-focus-outline

現在フォーカスされている要素の外側に、ページのCSSから独立したフォーカス枠を表示します。サイト側で `outline: none` が指定されている場合や、独自のフォーカス表示が見つけにくい場合の確認を補助します。

この表示自体はサイトが適切なフォーカスインジケーターを提供していることを意味しません。実際のサイト側表示との比較に使用してください。

## 使用方法

次のコードをブラウザのブックマークURLとして登録し、検査対象ページで実行します。Tabキーなどでフォーカスを移動すると枠が追従します。もう一度実行するか、右上の「終了」を押すと表示を削除します。

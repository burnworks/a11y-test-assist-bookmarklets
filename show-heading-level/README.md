# show-heading-level

`h1`〜`h6` と `role="heading"` の見出しレベルを表示します。

- 通常の見出し：情報色
- 直前の見出しからレベルが2段階以上深くなる場合：警告色
- `role="heading"` に有効な `aria-level` がない場合：エラー色
- ネイティブ見出しに `role="none"` / `presentation` が指定されている場合：エラー色

レベル飛びは確認候補として表示しますが、文書構造の妥当性を自動的に確定するものではありません。また、見出しのように見える通常要素は自動検出できないため、画面との比較が必要です。

## 使用方法

次のコードをブラウザのブックマークURLとして登録し、検査対象ページで実行します。もう一度実行するか、右上の「終了」を押すと表示を削除します。

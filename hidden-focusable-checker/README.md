# hidden-focusable-checker

`aria-hidden="true"` の範囲内に残ったTab移動先と、現在フォーカスされている要素を可視化します。

- `隠Tab`：支援技術から隠されている一方、Tabキーでフォーカスできる
- `隠Focus`：支援技術から隠されている要素へ現在フォーカスがある

`disabled`、`inert`、`display:none`、`visibility:hidden` などによって実際に利用できない要素は除外します。プログラムからだけフォーカスできる `tabindex="-1"` は、実際にフォーカスされている場合に表示します。

## 使用方法

次のコードをブラウザのブックマークURLとして登録し、検査対象ページで実行します。もう一度実行するか、右上の「終了」を押すと表示を削除します。

## 確認時の注意

`aria-hidden` は要素と子孫をアクセシビリティツリーから除外します。その範囲にフォーカスが移動すると、支援技術の利用者には対象を認識しにくくなります。検出結果を基に、`aria-hidden` の指定範囲、フォーカス制御、非表示状態の同期を確認してください。

参考：[ACT Rule: Element with aria-hidden has no content in sequential focus navigation](https://www.w3.org/WAI/standards-guidelines/act/rules/6cfa84/)

# non-html-link-highlighter

HTML以外のファイルを指すリンクを検出し、拡張子を表示します。URLのクエリ文字列やフラグメントは除外して判定します。

対象は `pdf`、`xls`、`xlsx`、`ods`、`csv`、`doc`、`docx`、`odt`、`rtf`、`ppt`、`pptx`、`odp`、`epub`、`zip` です。

短縮URL、ファイル共有サービス、拡張子を含まないダウンロードURLは判定できません。また、リンク文言からファイル形式が十分伝わるかは目視で確認してください。

## 使用方法

次のコードをブラウザのブックマークURLとして登録し、検査対象ページで実行します。もう一度実行するか、右上の「終了」を押すと表示を削除します。

# header-cell-scope-indicator

`th` 要素の `scope` 属性を分類して表示します。

- `row`、`col`、`rowgroup`、`colgroup`：正常値
- 属性なし：情報として表示
- 空値または上記以外：エラー表示

単純な表では `scope` の省略が直ちにエラーになるとは限りません。表の構造、見出しセルの位置、必要に応じて `headers` と `id` の関連付けも併せて確認してください。

## 使用方法

次のコードをブラウザのブックマークURLとして登録し、検査対象ページで実行します。もう一度実行するか、右上の「終了」を押すと表示を削除します。

# image-alt-attribute-checker

`img` と `input[type="image"]` の `alt` 属性を分類して表示します。

- `ALT`：空ではない値あり
- `ALT空`：空文字。装飾画像として妥当か要確認
- `ALT空白`：空白文字だけの値
- `ALTなし`：属性自体がない
- `ALT空!`：画像ボタン、または画像だけで構成されたリンク・ボタンのaltが空
- `ALT矛盾`：`role="none"` / `presentation` と空でないaltが併存

枠にマウスを重ねるか画像へフォーカスすると、alt値やARIAによる名前を右上のパネルに表示します。画像の目的や周辺文脈に対して代替テキストが適切かは目視で判断してください。

## 使用方法

次のコードをブラウザのブックマークURLとして登録し、検査対象ページで実行します。もう一度実行するか、右上の「終了」を押すと表示を削除します。

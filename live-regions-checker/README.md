# live-regions-checker

ARIAライブリージョンのDOM更新と、監視開始後の `ariaNotify()` 呼び出しを時系列で表示するブックマークレットです。カルーセル、タブ、検索結果、フォーム送信結果などで、支援技術へ何を通知しようとしているかを確認するのに使います。

## 監視対象

- `aria-live="polite"`、`assertive`、`off`
- 暗黙のライブリージョンを持つ `alert`、`status`、`log`、`marquee`、`timer` ロール
- ライブリージョン内のテキスト、要素、属性の追加・削除・変更
- `aria-atomic`、`aria-relevant`、`aria-busy` を考慮した通知候補
- `document.ariaNotify()` と `element.ariaNotify()` の文字列および `normal` / `high` 優先度

既存のライブリージョンは枠で示し、更新は右上のログへ新しい順に最大100件表示します。「一時停止」でログ追加を止め、「ログ消去」で現在の履歴を削除できます。

## 結果の読み方

ログは、ブラウザと支援技術へ通知される可能性があるDOM更新、またはAPI呼び出しを示します。実際にスクリーンリーダーが発話したことを保証するものではありません。ブラウザ、支援技術、フォーカス、`aria-busy`、`aria-relevant`、更新タイミングなどによって結果は異なるため、最後は実際の組み合わせでも確認してください。

`ariaNotify()` はWAI-ARIA 1.3で定義されていますが、まだ対応していないブラウザがあります。APIが存在しない場合、このブックマークレットは偽のメソッドを追加せず、ライブリージョンだけを監視します。

## 制限事項

- 実行前に完了した更新や `ariaNotify()` 呼び出しは取得できません。
- 実行前に別変数へ保存・bindされた元の `ariaNotify()` 関数を直接呼ぶコードは捕捉できません。
- cross-origin iframeとclosed Shadow DOMの内部は監視できません。
- prototypeが変更不可になっているページでは `ariaNotify()` をラップできない場合があります。
- ブックマークレット終了時には、ラップしたメソッドをページ側が途中で置き換えていない場合に限り元へ戻します。

参考：[WAI-ARIA 1.3 ARIANotifyMixin](https://www.w3.org/TR/wai-aria-1.3/#ARIANotifyMixin)、[MDN ariaNotify()](https://developer.mozilla.org/docs/Web/API/Document/ariaNotify)

## 使用方法

次のコードをブラウザのブックマークURLとして登録し、先に監視を開始してから対象UIを操作します。もう一度実行するか、右上の「終了」を押すと監視とラップを解除します。

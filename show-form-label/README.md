# show-form-label

フォームコントロールと一般的なウィジェットロールについて、確認できた名前と取得元を表示します。

- `NAME`：`aria-labelledby`、`aria-label`、`label`、内容テキスト、ボタン値、画像ボタンのaltから名前を取得
- `titleのみ` / `placeholderのみ`：名前の代替として使われている可能性があるため警告
- `名前なし`：名前を確認できない

ARIAの参照をネイティブの `label` より先に評価し、複数のlabelや、label内の画像のaltも扱います。ただしブラウザのアクセシビリティツリーを直接取得するものではなく、Accessible Name計算の実用的な近似です。最終確認にはブラウザのアクセシビリティ開発者ツールも併用してください。

## 使用方法

次のコードをブラウザのブックマークURLとして登録し、検査対象ページで実行します。もう一度実行するか、右上の「終了」を押すと表示を削除します。

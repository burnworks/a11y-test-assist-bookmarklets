# target-size-checker

リンク、ボタン、フォームコントロール、一般的なARIAウィジェットなどのポインターターゲットを測定し、幅または高さが24 CSS px未満の要素を表示します。WCAG 2.2達成基準2.5.8の例外を確認しやすいよう分類します。

- `小:密集`：小さく、近接する別のターゲットがある要確認候補
- `小:間隔`：小さいが、24 CSS pxの円による間隔を確保している候補
- `小:行内`：文章中の行内リンクの例外候補

## 使用方法

次のコードをブラウザのブックマークURLとして登録し、検査対象ページで実行します。枠にマウスを重ねるか対象へフォーカスすると、測定値を表示します。もう一度実行するか、右上の「終了」を押すと表示を削除します。

## 確認時の注意

測定は表示中のCSSピクセルに基づく補助判定です。行内リンク、同等機能を持つ別ターゲット、ユーザーエージェントが決めるコントロール、表示上不可欠なサイズなどの例外は人が判断してください。疑似要素で広げたクリック領域、イベント委譲、座標変換、ページ固有のポインター処理はDOMの矩形だけでは正確に判定できない場合があります。

参考：[Understanding Success Criterion 2.5.8: Target Size (Minimum)](https://www.w3.org/WAI/WCAG22/Understanding/target-size-minimum)

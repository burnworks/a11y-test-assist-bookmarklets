# dialog-focus-checker

開いているネイティブの `dialog` と `role="dialog"`／`role="alertdialog"` を検出し、名前、モーダル状態、現在のフォーカス位置を表示します。モーダルの外に残ったTab移動先を囲み、実行中にフォーカスが外へ移動した場合はログへ記録します。

- `DLG:modal`／`DLG:modeless`：ダイアログ本体
- `外Tab`：モーダルダイアログの外にあるTab移動先
- フォーカス逸脱ログ：監視開始後にモーダル外へ移った履歴

## 使用方法

次のコードをブラウザのブックマークURLとして登録し、ダイアログを開いた状態で実行します。その後Tab／Shift+TabやEscapeキーなどを操作してください。もう一度実行するか、右上の「終了」を押すと表示と監視を削除します。

## 確認時の注意

`aria-modal="true"` はそれ自体でフォーカスを閉じ込めたり、背景を操作不能にしたりしません。`外Tab` はDOM上の候補なので、実際のTab操作でも外へ移動するか確認してください。また、開いた直後の初期フォーカス、閉じた後に呼び出し元へ戻ること、Escapeキーの動作、背景のポインター操作も確認が必要です。

参考：[WAI-ARIA APG: Dialog (Modal) Pattern](https://www.w3.org/WAI/ARIA/apg/patterns/dialog-modal/)

# aria-reference-checker

ARIAおよびHTMLのID参照を可視化し、参照切れ、重複ID、要素型の不一致、循環参照などを検出します。

対象は `aria-labelledby`、`aria-describedby`、`aria-controls`、`aria-owns`、`aria-flowto`、`aria-activedescendant`、`aria-details`、`aria-errormessage`、`headers`、`for`、`list`、`form`、`popovertarget` です。

- `REF`：参照先を一意に確認できた
- `REF?`：自己参照、循環、`aria-activedescendant`の関係などを要確認
- `REF!`：参照切れ、空値、重複ID参照、対象要素型の不一致
- `ID×n`：同じDOMツリー内の重複ID

Shadow DOMではID参照のスコープが別になるため、各Document／ShadowRoot単位で検査します。結果は文法・参照関係の補助確認であり、参照先の内容や関係性が適切かは目視で判断してください。

## 使用方法

次のコードをブラウザのブックマークURLとして登録し、検査対象ページで実行します。もう一度実行するか、右上の「終了」を押すと表示を削除します。

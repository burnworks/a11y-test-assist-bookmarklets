# focusable-element-checker

Tabキーで順次フォーカスできる要素をページ上で番号表示します。正の `tabindex` は警告色で示し、`role` や `onclick` により操作可能に見えるのにTab順へ含まれない要素は「Tab不可」と表示します。

radioグループは実際のTab移動に合わせ、選択済みの項目、未選択なら先頭の項目を1つのTab停止位置として扱います。`disabled`、無効な `fieldset` 内、`inert` 内、非表示の要素は除外します。

これはキーボード操作の可否を自動判定するものではありません。表示された順序で実際にTabキーを操作し、フォーカス表示、操作、順序を確認してください。

## 使用方法

次のコードをブラウザのブックマークURLとして登録し、検査対象ページで実行します。もう一度実行するか、右上の「終了」を押すと表示を削除します。

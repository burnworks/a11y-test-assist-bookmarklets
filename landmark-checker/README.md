# landmark-checker

ページのランドマークを枠で囲み、役割、アクセシブルな名前、役割の取得元を表示します。HTML要素による暗黙のランドマークとARIAの明示的なランドマークの両方が対象です。

- `LM:main` のようなラベル：ランドマークの役割
- `LM:navigation「Primary」` のようなラベル：役割と名前
- 黄枠：複数の `main`／`banner`／`contentinfo`、同じ役割を識別できない名前、名前のない明示的な `region`／`form` などを要確認

## 使用方法

次のコードをブラウザのブックマークURLとして登録し、検査対象ページで実行します。もう一度実行するか、右上の「終了」を押すと表示を削除します。

## 確認時の注意

ランドマークがページ構成を適切に表しているか、同種のランドマークを名前で区別できるかを目視で確認してください。`header` と `footer` はセクショニング要素の内側ではそれぞれ `banner`、`contentinfo` として扱いません。名前のある `form` と `section` は暗黙のランドマークとして表示します。

参考：[WAI-ARIA APG: Landmark Regions](https://www.w3.org/WAI/ARIA/apg/practices/landmark-regions/)
